# KolourPaint

KolourPaint is a simple, easy-to-use paint program for KDE. It features basic drawing tools like brush, pencil, shapes, text, and color picker, making it ideal for quick image editing, sketching, and simple graphics work. It supports common image formats including PNG, JPEG, BMP, and more.

This is an **Aurelis Linux** package, but it can also run as a regular AppImage on any Linux distribution.
